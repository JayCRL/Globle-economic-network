# Globle-economic-network · 共同网络

> 生产可以分布式，规则可以共同制定，未来仍由人类共同选择。

![页面预览](docs/preview.jpg)

一个单文件的可视化网页，用一页讲清楚一套关于 **分层联邦式全球经济网络** 的制度构想：
AI 放大个人生产能力之后，经济组织不必只剩「庞大的层级企业」这一条路——个人与 AI
成为灵活的生产单元，国家保留自治与制度选择权，全球通过公共协议连接资源与能力，
而最终的规则制定权仍然留在人手里。

页面本身不依赖任何框架、外链字体或 CDN，一个 `.html` 文件即可离线打开。

## 四层模型速览

1. **个人与生产单元** —— 个人 + AI 成为更完整、更可组合的生产者，公司、合作社与公共机构并存。
2. **国家经济网络** —— 国家继续负责公共服务、社会保障与产业政策，同时建设跨境协作能力。
3. **全球互联网络** —— 由共同协议（身份、标准、授权、结算、争议处理）连接的网络，而非超级企业。
4. **全球共同治理** —— 只处理跨国公共问题，并配有明确授权、双重代表、独立审计与纠错机制。

## 核心原则

- **开放互联，而非平台垄断**：互操作、数据可迁移、多供应商，避免单一入口。
- **自治协作，而非单一中心**：跨边界问题才上交更高层级。
- **共享调用，也讨论所有权**：使用权、收益权、控制权、责任归属必须分开说清。
- **发展可达，而非永久分级**：接入可以分阶段，但不能固化不平等。
- **效率与公平共同衡量**：成本与产出之外，还要看保障、议价能力、区域差距和生态代价。
- **权力可审计、可问责**：规则、分配与算法辅助决策都应可解释、可申诉。

## 运行

直接用浏览器打开即可，不需要构建：

```bash
# 方式一：双击
global-economic-network.html

# 方式二：起一个本地静态服务（推荐，便于测试相对路径与分享）
python -m http.server 8000
# 然后访问 http://localhost:8000/global-economic-network.html
```

## 发布到 GitHub Pages（可选）

GitHub Pages 需要一个 `index.html` 作为入口。若希望直接在线访问，可以这样做：

```bash
# 把页面改名为入口文件，然后推送
git mv global-economic-network.html index.html
```

然后在仓库 **Settings → Pages** 中选择 `main` 分支的根目录（`/`）并保存，稍后访问
`https://jaycrl.github.io/Globle-economic-network/`。

## 技术说明

- **单文件、零依赖**：HTML + 内联 CSS + 原生 JavaScript，无构建步骤、无第三方请求。
- **响应式**：三档断点（800px / 520px），移动端将架构图改为纵向堆叠。
- **可访问性**：
  - 语义化结构（`header` / `nav` / `main` / `section` / `footer`），支持「跳到主要内容」；
  - 四层结构使用标准 `tablist` / `tab` / `tabpanel` 模式，支持 `↑ ↓ ← → Home End` 键盘操作；
  - 装饰性符号统一 `aria-hidden`，提供可见焦点样式与 `aria-current` 导航高亮。
- **动效克制**：滚动进入淡入、顶部阅读进度条、导航高亮；在 `prefers-reduced-motion` 下全部关闭。
- **可打印**：`@media print` 下自动转为浅色版式。
- **分享**：内置 `og:` / `twitter:` 元信息与内联 SVG favicon。

## 说明与边界

这是一份 **概念讨论稿**，不是已经存在的制度，也不是技术方案书。它的可行性取决于
技术能力、资源产权、国家间信任，以及人类能否建立真正具有代表性与问责能力的共同治理机制。
页面刻意保留了大量「开放问题」，因为比起给出答案，更重要的是先把问题摆清楚。
